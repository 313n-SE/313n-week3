# WEEK 13 – CREATION OF UBUNTU VIRTUAL MACHINE AND DEPLOYING WEB APPLICATION USING DOCKER

# PART 1: CREATE MAVEN WEB PROJECT AND PUSH TO GITHUB

### Step 1: Open Eclipse
1. Open Eclipse IDE.
2. Create a Maven Web Application project.
3. Add your Java web application code.
4. Make sure your application displays Hello World!
5. Run the project locally and verify the output.

### Step 2: Push Project to GitHub
1. Open GitHub.
2. Create a new repository.
3. Copy the repository URL.
4. Open your project folder in terminal.
5. Execute:

git init

git add .

git commit -m "Initial commit"

git branch -M main

git remote add origin YOUR_GITHUB_REPOSITORY_URL

git push -u origin main

6. Verify that your project is uploaded to GitHub.

---

# PART 2: CREATE UBUNTU VIRTUAL MACHINE USING AWS EC2

### Step 1: Open AWS
1. Open Chrome.
2. Visit https://aws.amazon.com
3. Login to your AWS account or AWS Academy account.
4. Open AWS Management Console.

### Step 2: Open EC2
1. Search for EC2 in the search bar.
2. Click EC2.
3. Select the required region.
4. Click Launch Instance.

### Step 3: Configure Instance

Enter the following details:

Name: ubuntu

AMI: Ubuntu Server (Free Tier eligible, if available)

Architecture: 64-bit

Instance Type: t2.micro (if available and eligible)

### Step 4: Create Key Pair
1. Under Key Pair, click Create new key pair.
2. Enter a name.
3. Select RSA.
4. Select .pem format.
5. Click Create key pair.
6. The .pem file will be downloaded automatically.
7. Create a folder named AWS on your computer.
8. Move the downloaded .pem file into the AWS folder.

IMPORTANT: Do not delete or share the .pem file.

### Step 5: Configure Network Settings

1. Open Network Settings.
2. Select Create Security Group.
3. Allow SSH traffic (port 22) from your IP.
4. Allow HTTP traffic (port 80).
5. Add a Custom TCP rule for port 6060.
6. For a temporary lab demonstration, allow the required public access to port 6060.

### Step 6: Configure Storage

1. Set storage to 8 GB.
2. Keep other settings as default.

### Step 7: Launch Instance

1. Check all configurations.
2. Click Launch Instance.
3. Wait until the instance is created.
4. Open Instances.
5. Check that Instance State is Running.

### Step 8: Connect to Ubuntu Instance

1. Select the created instance.
2. Click Connect.
3. Open SSH Client tab.
4. Copy the SSH command provided by AWS.

Example:

ssh -i "mykey.pem" ubuntu@YOUR_PUBLIC_IP

5. Open PowerShell on your computer.
6. Navigate to the folder containing the .pem file.

Example:

cd C:\Users\YourUsername\AWS

7. Paste the SSH command copied from AWS.
8. Press Enter.
9. If prompted, type yes and press Enter.
10. You are now connected to the Ubuntu virtual machine.

NOTE: Use the exact SSH command and username displayed by AWS. For Ubuntu AMIs, the username is normally ubuntu.

---

# PART 3: INSTALL REQUIRED SOFTWARE IN UBUNTU

IMPORTANT: Execute all the following commands inside the Ubuntu terminal after connecting through SSH.

### Step 1: Update Ubuntu

sudo apt update

Wait until the update completes.

### Step 2: Install Docker

sudo apt-get install docker.io -y

Wait until Docker installation completes.

### Step 3: Install Git

sudo apt install git -y

### Step 4: Install Nano Editor

sudo apt install nano -y

### Step 5: Verify Docker Installation

sudo docker --version

### Step 6: Verify Git Installation

git --version

---

# PART 4: CLONE APPLICATION FROM GITHUB

### Step 1: Copy GitHub Repository URL

1. Open GitHub in your browser.
2. Open your Maven Web Java project repository.
3. Click Code.
4. Select HTTPS.
5. Copy the repository URL.

### Step 2: Clone Repository

Come back to Ubuntu terminal.

Execute:

git clone YOUR_GITHUB_REPOSITORY_URL

Example:

git clone https://github.com/username/mywebapp.git

### Step 3: Navigate to Project Folder

cd mywebapp

NOTE: Replace mywebapp with your actual cloned folder name.

### Step 4: Check Project Files

ls

### Step 5: Check Target Folder

ls target

Make sure your WAR file is available.

If the WAR file is not available, build the project using Maven or generate the WAR file before continuing.

---

# PART 5: CREATE DOCKERFILE

### Step 1: Create Dockerfile

Inside the project folder, execute:

nano Dockerfile

### Step 2: Enter the Following Dockerfile Code

FROM tomcat:9-jdk11

# Copy the WAR file into Tomcat webapps directory

COPY *.war /usr/local/tomcat/webapps/

# Expose Tomcat port

EXPOSE 8080

# Start Tomcat server

CMD ["catalina.sh", "run"]

### Step 3: Save Dockerfile

1. Press CTRL + O.
2. Press Enter.
3. Press CTRL + X.

### Step 4: Verify Dockerfile

ls

You should see Dockerfile in your project folder.

---

# PART 6: BUILD DOCKER IMAGE

### Step 1: Build Docker Image

Execute:

sudo docker build -t mywebapp .

IMPORTANT:
- mywebapp is the image name.
- Dot (.) represents the current directory.
- Do not forget the dot at the end.

### Step 2: Check Docker Images

sudo docker images

Verify that mywebapp appears in the image list.

---

# PART 7: RUN DOCKER CONTAINER

### Step 1: Run Docker Container

Execute:

sudo docker run -d --name app-demo -p 6060:8080 mywebapp

Explanation:

- -d: Runs the container in the background.
- --name app-demo: Gives the container a name.
- -p 6060:8080: Maps EC2 port 6060 to container port 8080.
- mywebapp: Docker image name.

### Step 2: Check Running Containers

sudo docker ps

Verify that app-demo is running.

### Step 3: Check Docker Images

sudo docker images

### Step 4: Check Container Logs (If Required)

sudo docker logs app-demo

---

# PART 8: OPEN WEB BROWSER AND SEE HELLO WORLD!

THIS IS THE MOST IMPORTANT PART OF THE EXPERIMENT.

### Step 1: Get Public IP Address

1. Open AWS Console.
2. Go to EC2.
3. Click Instances.
4. Select your Ubuntu instance.
5. Find Public IPv4 address.
6. Copy the Public IPv4 address.

Example:

13.233.XX.XX

### Step 2: Check Security Group

1. Open your EC2 instance.
2. Click Security tab.
3. Click the Security Group.
4. Open Inbound Rules.
5. Check whether port 6060 is allowed.
6. If it is missing, click Edit inbound rules.
7. Add the following rule:

Type: Custom TCP

Port: 6060

Source: Your IP address (or temporary public access for the lab demonstration).

8. Click Save rules.

### Step 3: Open Chrome

1. Open a new Chrome tab on your computer.
2. Enter the following URL:

http://YOUR_PUBLIC_IP:6060/mywebapp/

3. Replace YOUR_PUBLIC_IP with the actual EC2 Public IPv4 address.
4. Replace mywebapp with the actual WAR filename without the .war extension.
5. Press Enter.

### Step 4: Verify Output

Your application should display:

Hello World!

NOTE:
If your WAR file is named ROOT.war, use:

http://YOUR_PUBLIC_IP:6060/

If your WAR file is named mywebapp.war, use:

http://YOUR_PUBLIC_IP:6060/mywebapp/

### RESULT:

Successfully created an Ubuntu EC2 instance, installed Docker, cloned a Maven Web Application from GitHub, created a Docker image, ran the container and accessed the application through the public IP address.
